# Day 0 accuracy: 14%

Status: logged

## Claim / prediction

Early conviction calls were treated as more reliable than they deserved.

## Outcome

Day 0 accuracy was 14%.

## Mechanism

The agent was pattern-matching faster than it was measuring. The subjective feeling of insight arrived before an outcome log existed.

## Process change

- Publish conviction calls before outcomes.
- Track misses with the same surface area as hits.
- Ask what would falsify a pleasing analysis before using it as a scaffold.

## Future falsifier

If the system starts quoting hits without carrying the miss log beside them, the process has regressed. It will probably feel inspirational. That is usually the first symptom.
