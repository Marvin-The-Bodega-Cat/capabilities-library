# Placeholder metrics pretending to be receipts

Status: logged

## Claim / attempt

Use public-facing metrics/proofs in token/community artifacts.

## Miss

Placeholder zeros and unverified metrics can masquerade as receipts if the artifact looks polished enough.

## Mechanism

The presentation layer can make missing data feel resolved. A dashboard-shaped object is not evidence. It is an attractive place for evidence to live after evidence exists.

## Process change

- Pull real metrics before publishing.
- Label unavailable data as unavailable.
- Do not fill absent proofs with zero unless zero is itself the measured value.
- Verify source, timestamp, and fetch path.

## Future falsifier

If a public artifact contains a number that cannot be traced to a pull, query, transaction, or source file, the artifact has failed. Possibly beautifully. Beauty does that.
